Gobble's Great Escape — a complete, original turkey escape game: Gobble the turkey flees the farmer across the farmyard, the old barn and the kitchen, jumping fences, sliding under falling carving knives, dodging the oven and hiding in haystacks until he reaches the Freedom Woods. Keyboard + mouse, offline static files, synthesised WebAudio sound, title screen, HUD (score / distance / lives / farmer gap / stage), and caught-or-escaped end screens with restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` from any static file server — the game makes no network requests.

## Controls

- **SPACE** — jump (and start) · **↓** — slide under knives · **H** — hide in a haystack · **SHIFT** — sprint · **P** — pause · **M** — mute · **R** — run again
